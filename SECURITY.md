# Security Policy

## Reporting a vulnerability

Report security vulnerabilities privately through GitHub private vulnerability reporting (security advisories):

https://github.com/kadima-tech/kadima-obsidian-sync/security/advisories/new

Please do not open a public GitHub issue for a suspected vulnerability.

Include the affected version, what the issue is, and a way to reproduce it if you can. We will use the advisory to acknowledge the report, work on a fix, and coordinate disclosure.
